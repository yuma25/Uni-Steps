# Uni-Steps アプリケーション概要

## 1. コンセプト
**「AIと仲間が，あなたの『一歩』を支える」**
グループ内での予定共有にAIが介入し，最適なタイミングとメッセージでリマインドを行うことで，タスクの完遂と良好な生活リズムを支援する．

## 2. コア機能
*   **AIスマートタスク登録**: 曖昧な自然言語入力から，期限や重要度を自動抽出する．
*   **マルチソース・インテグレーション**:
    *   **手動入力**: UI から詳細な情報（タイトル，期限，担当者，隔週設定等）を直接入力できる．
    *   **LMS 連携**: Google Classroom（デフォルト）や Web Class などの学習管理システムから課題を自動取得する．
*   **ハイブリッド通知システム**:
    *   **LINE グループ**: 朝晩のサマリー報告，生存確認（起床確認）を行う．
    *   **Web Push (個人)**: 期限直前の緊急アラート，個別の喝入れを行う．
*   **クリティカル起床確認**: 絶対に外せない予定がある日の朝，本人が起きていない場合にグループへ自動的にヘルプ要請を行う．

## 3. ユーザー体験 (UX)
1.  **登録**: 「明日10時の会議，絶対起こして」とチャット感覚で入力する．
2.  **監視**: Goのバックエンドが24時間，裏側で期限と起床予定を監視する．
3.  **通知**: 適切なタイミングでAIが生成した「心に刺さる」メッセージが届く．
