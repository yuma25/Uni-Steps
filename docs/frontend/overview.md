# フロントエンド アーキテクチャ概要

Uni-Steps のフロントエンドは，Vite + React + TypeScript を基盤とし，保守性とスケーラビリティに優れたモダンな設計を採用している．

## 🏗 ディレクトリ構造

各レイヤーの責務を明確に分離している：

- `src/api/`: バックエンドとの HTTP 通信をカプセル化したモジュール群である．
- `src/components/`: 再利用可能な UI 部品である．
  - `layout/`: `AppShell` 等，アプリの枠組みを定義する部品である．
  - `dashboard/`: `HomeOverview` や `TaskCard` 等，ダッシュボード専用の部品である．
  - `modals/`: 入力フォーム等のポップアップ表示部品である．
- `src/context/`: `AuthContext` をはじめとするアプリ全体で共有する状態である．
- `src/hooks/`: ビジネスロジックやデータ取得を抽象化したカスタムフックである．
- `src/pages/`: 各画面のメインエントリーポイントである．

## 🔄 主要な仕組み

1.  **AppShell アーキテクチャ**:
    - PC 画面ではサイドバー，スマホ画面ではボトムナビゲーションへと自動で切り替わるレスポンシブな枠組みを採用している．
2.  **同時出現 UI (Full Page Loading)**:
    - 部屋に入った際，全ての必要なデータ（課題，メンバー状況等）が揃うまでローディング画面を維持し，準備が整った瞬間に全 UI を一斉に表示させる仕組みである．
3.  **認証と状態共有**:
    - `AuthContext` がログインユーザーの情報を一括管理し，`useAuth` フックを通じてアプリのどこからでもユーザー情報へアクセスできる．
4.  **データ取得の集約**:
    - `useDashboardData` フックがダッシュボードに必要な多種多様な情報を並列で取得し，ページへ供給する．
