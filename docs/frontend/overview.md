# フロントエンド アーキテクチャ概要

Uni-Steps のフロントエンドは，Vite + React + TypeScript を基盤とし，保守性とスケーラビリティに優れたモダンな設計を採用している．

## 🏗 ディレクトリ構造

各レイヤーの責務を明確に分離している：

- `src/api/`: バックエンドとの HTTP 通信をカプセル化したモジュール群である．
- `src/components/`: 再利用可能な UI 部品である．
  - `dashboard/`: ダッシュボード専用の複雑な部品である．
  - `modals/`: 入力フォーム等のポップアップ表示部品である．
- `src/context/`: `AuthContext` をはじめとするアプリ全体で共有する状態（共有箱）である．
- `src/hooks/`: ビジネスロジックやデータ取得を抽象化したカスタムフックである．
- `src/pages/`: 各画面のメインエントリーポイントである．
- `src/utils/`: 日付変換や共通の変換ロジックを保持するヘルパー関数群である．

## 🔄 データフロー

1.  **認証**: `AuthContext` が URL パラメータから `user_id` を検知し，自動的にユーザー情報を取得・保持する．
2.  **データ取得**: `useDashboardData` フックが並列（`Promise.allSettled`）で必要なデータを一括取得し，画面へ供給する．
3.  **通知制御**: `useWebPush` フックが購読状態の監視と 410 エラー（通知切れ）からの自動復旧を管理する．
4.  **同期**: ページ読み込み時に `handleSync` が自動実行され，LMS との最新状態を維持する．
