# フロントエンド コンテキスト（状態共有） リファレンス

アプリ全体で共有されるデータ保持の仕組みである．

---

## 🔹 `AuthContext`
現在ログインしているユーザーの情報をツリー全体に供給する．

### **提供される値 (`AuthContextType`)**
- `userId string`: URL パラメータ `user_id` から自動抽出された ID．
- `user User | null`: サーバーから取得したユーザー詳細オブジェクト．
- `loading boolean`: ユーザー情報の取得中フラグ．
- `refreshUser func`: ユーザー情報を手動で再取得する関数．

---

## 🏗 `AuthProvider`
`AuthContext` の値を実際に保持し，子コンポーネントへ提供するラッパーコンポーネントである．
- **初期化ロジック**: 
  - マウント時に URL の `user_id` を確認し，存在すれば `userApi.getMe` を呼び出して詳細を取得する．
  - `user_id` が存在しない場合は，自動的にログイン画面へリダイレクトを促す（Page レベルで判定）．
