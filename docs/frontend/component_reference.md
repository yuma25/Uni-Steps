# フロントエンド コンポーネント リファレンス

ダッシュボードを構成する主要な UI 部品の仕様である．

---

## 📁 Dashboard Components

### ⚛️ `HomeOverview` (NEW)
ダッシュボード最上部に表示される，パーソナライズされたサマリー部品である．
- **機能**: 
  - 時間帯に応じたパーソナライズされた挨拶．
  - 「あなたのタスク（未完了分）」「今日の締め切り」「全課題」の統計表示．

### ⚛️ `DashboardHeader`
ダッシュボード上部のナビゲーションを管理する部品である．
- **機能**: 
  - 部屋名，所属メンバー名（直接表示）の確認．
  - 招待コードのコピー機能．
  - **手動同期アクション**: Google Classroom から最新の課題を取得する「同期」ボタンを提供し，実行中はアイコンが回転して状態を知らせる．
  - **同期ステータス表示**: 同期ボタン内に「最終同期時刻（HH:mm）」を表示し，現在のデータの鮮度を可視化する．
  - 課題登録，Web Push テスト/有効化の各アクションボタン．

### ⚛️ `WakeupSection`
起床見守りに関する統合 UI である．
- **機能**: 
  - 自身の予約状況の確認，編集，削除（ホバー効果付き）．
  - メンバー全員の状況（本日起きたか，予定なしか等）を常時表示するリスト．

### ⚛️ `TaskCard`
課題情報の表示と操作を担うカード部品である．
- **機能**: 
  - 出典（Classroom/手動）に応じたアイコン表示．
  - **権限管理**: 作成者またはオーナーのみが編集/削除可能．
  - **完了管理**: 手動課題のみ完了/戻す操作が可能．

---

## 📁 Layout & Modal Components

### ⚛️ `AppShell`
PC 版サイドバーとスマホ版ボトムナビを切り替える，アプリ全体の骨格部品である．
- **スマホ版ナビ**: モダンな「フローティング・ピル（カプセル型）」かつグラスモーフィズムを採用し，操作性を向上させている．

### ⚛️ `TaskModal`
課題の登録および詳細編集用フォームである．担当者の複数選択（自分のみ/全員）の権限管理を含む．
- **モバイル対応**: 下からスライドする「ボトムシート」形式を採用し，狭い画面でも快適に入力できる．

### ⚛️ `WakeupModal`
起床時間を予約するためのフォームである．SOS 警告メッセージを含む．
- **モバイル対応**: `TaskModal` 同様，ボトムシート形式で実装されている．
