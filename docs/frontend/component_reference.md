# フロントエンド コンポーネント リファレンス

ダッシュボードを構成する主要な UI 部品の仕様である．

---

## 📁 Dashboard Components

### ⚛️ `DashboardHeader`
ダッシュボード上部のナビゲーションとアクションを管理する部品である．
- **機能**: 
  - 部屋名，招待コードの表示とコピー．
  - 同期，課題追加，設定のトリガー．
  - Web Push 通知の購読ボタン（必要な時のみ表示）とテストボタン．

### ⚛️ `WakeupSection`
起床見守りに関する状態表示とアクションを担う部品である．
- **機能**: 
  - 自身の起床予定の表示，変更，キャンセル，チェックイン．
  - グループメンバー全員の起床ステータス一覧の表示．

### ⚛️ `TaskCard`
課題一つの情報を表示するカード部品である．
- **機能**: 
  - タイトル，期限，メンバー別進捗バッジの表示．
  - 編集ボタン，完了/未完了の切り替えボタン．
- **制約**: Classroom 由来の固定期限課題は編集ボタンが表示されない．

### ⚛️ `TimelineSection`
AI からのメッセージや SOS 履歴を表示する活動フィードである．

---

## 📁 Modal Components

### ⚛️ `TaskModal`
課題の登録および編集用フォームである．

### ⚛️ `SettingsModal`
部屋のカスタマイズ（AI 性格，LINE 連携，通知間隔，サマリー時刻）を行うフォームである．

### ⚛️ `WakeupModal`
起床時間を予約するためのフォームである．
