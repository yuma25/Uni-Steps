# LINE Messaging API 連携設定ガイド

本ドキュメントでは，Uni-Steps から LINE グループへリマインド通知を送信するために必要な，LINE Developers での設定手順を詳細に解説する．

---

## 1．LINE Developers アカウントの準備
LINE の開発者用ポータルを利用するための準備を行う．

1.  [LINE Developers Console](https://developers.line.biz/console/) にログインする．（個人の LINE アカウントまたはビジネスアカウントを使用する．）
2.  **プロバイダーの作成**:
    *   「プロバイダー（作成者）」がまだ存在しない場合は，「作成」ボタンから新規作成する．
    *   プロバイダー名： `Uni-Steps-Project` (任意)

## 2．チャネルの作成
実際に通知を送る「Bot」の役割を果たすチャネルを作成する．

1.  作成したプロバイダー内で **「新規チャネル作成」** をクリックし，**「Messaging API」** を選択する．
2.  必要事項を入力する：
    *   チャネルの種類： `Messaging API`
    *   チャネル名： `Uni-Steps リマインダー`
    *   チャネル説明： `課題の期限や起床確認を通知する Bot である．`
    *   大業種・小業種： 適切に選択する（例：教育・習い事）．
    *   メールアドレス： 自身のメールアドレス．
3.  規約に同意して「作成」をクリックする．

## 3．チャネルアクセストークンの発行
アプリケーション（Go バックエンド）が LINE の API を叩くための認証キーを取得する．

1.  作成したチャネルのページで，上部のタブから **「Messaging API 設定」** を選択する．
2.  一番下までスクロールし，**「チャネルアクセストークン（長期）」** セクションの **「発行」** ボタンをクリックする．
3.  表示された非常に長い文字列をコピーし，`.env` ファイルの `LINE_CHANNEL_TOKEN` に設定する．

## 4．LINE グループへの招待と ID の取得
Bot を特定のグループに招待し，そのグループにメッセージを送るための ID を特定する．

1.  **Bot の追加**:
    *   「Messaging API 設定」タブにある QR コードをスマホで読み取り，Bot を友だち追加する．
2.  **グループへの招待**:
    *   通知を飛ばしたい LINE グループに，追加した Bot を招待する．
3.  **グループ ID の特定**:
    *   Messaging API では，グループ ID（`G` から始まる ID）をプログラム側で受け取る必要がある．
    *   最も簡単な方法は，Bot をグループに入れた状態でメッセージを送信し，バックエンドのログに表示される Webhook イベント（`source.groupId`）を確認することである．
    *   ※開発中は，自身のユーザー ID（「チャネル基本設定」タブの下部にある）をテスト送信先として使用することも可能である．

## 5．環境変数の設定
取得した値をプロジェクトルートの `.env` ファイルに設定する．

```text
LINE_CHANNEL_TOKEN="[取得したチャネルアクセストークン]"
```

## 6．補足：Webhook の設定（任意）
Bot がユーザーからのメッセージに反応する必要がある場合（チャット機能等）は，以下の設定を行う：
1.  「Messaging API 設定」の **「Webhook URL」** に，`https://[RenderのURL]/api/line/webhook` を設定する．
2.  **「Webhook の利用」** を ON にする．
